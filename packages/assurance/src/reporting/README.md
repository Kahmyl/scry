# Reporting

Reporting presents Assurance findings.

Reports do not manufacture truth and are not themselves the authoritative
execution evidence store.

`synthesizeExperiment()` remains the factual metric comparison for one
baseline/candidate experiment. Sibling-experiment synthesis is a separate
higher-level layer: it normalizes immutable cluster evidence, classifies shared
and distinct signatures, and validates a structured remediation proposal.

Every material proposal statement must reference evidence already present in
the normalized bundle. Optional agent output passes through the same validator;
an unsupported model assertion is not a finding. Foundational viability also
requires one of the explicit architectural threshold signals.

Synthesis has no patch, branch, merge, deployment, or authorization authority.
It always returns a human-authorization requirement.
