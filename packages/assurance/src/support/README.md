# Capability support

Support classification is derived from Assurance evidence.

The classifier is deliberately conservative:

- evidence-backed test success can establish `experimental`;
- unanimous evidence-backed qualification can establish `qualified`;
- unanimous evidence-backed certification can establish `certified`;
- ordinary real-run evidence is tracked separately as
  `observedInRealApplications`;
- missing, contradictory, inconclusive, or evidence-free results never
  manufacture a stronger support claim.

`unsupported` is intentionally not inferred here. Declaring that a capability
is unsupported is a product/support-policy statement, not something Assurance
may derive merely from absence of proof or an isolated failure.
