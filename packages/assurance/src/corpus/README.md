# Assurance corpus

The corpus records reusable evidence about where Scry succeeds, fails, falls
back, recovers, or approaches operational limits.

The useful unit is capability × environment, not simply website.

Environment dimensions may include:

- control type;
- framework behavior;
- page lifecycle;
- navigation behavior;
- authentication style;
- acquisition method;
- mutation semantics;
- journey depth;
- failure/recovery class.

The corpus does not authorize runtime behavior. It is evidence for
qualification, investigation, experimentation, support classification, and
future fixture/campaign selection.
