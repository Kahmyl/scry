# Observability

Assurance observability consumes safe factual observations.

It is deliberately downstream of Scry runtime:

```text
runtime / Chronicle facts
        ↓
safe observation adapter
        ↓
Assurance experience corpus
```

Production execution must not import Assurance or wait for Assurance.

Observations may describe:

- native resolution success;
- Praxis fallback;
- target ambiguity;
- semantic/continuation turns;
- latency;
- document epoch changes;
- recovery;
- cleanup escalation;
- capability/environment dimensions.

Raw secrets, credentials, browser handles, raw DOM, and execution-authority
objects do not belong in the Assurance observation contract.

Metrics are facts, not verdicts. Support classification is derived separately
from accumulated evidence.
