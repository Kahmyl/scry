# Verification

A verification establishes one explicit factual claim.

Every verification identifies:

1. the claim being tested;
2. the oracle that decides whether the claim holds;
3. the evidence supporting that decision.

A pass without evidence is not a pass. Assurance converts it to
`inconclusive`.

A fail without evidence is also converted to `inconclusive`.

Where practical, the subsystem being tested must not be the sole authority
for deciding whether it worked.
