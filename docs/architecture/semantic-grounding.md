# Capability-grounding authority

Scry resolves the live control that can safely perform an intended action. A Flow states required capabilities, preferred evidence, scope, relationships, prohibited states, risk, and confidence policy. Roles, labels, OCR text, layout, accessibility, history, and native HTML properties are evidence; none is an independent bypass around the universal gate.

The deterministic path is:

```text
resolve scope
→ inventory actionable controls
→ collect native, accessibility, textual, structural, visual, runtime, and historical evidence
→ apply capability, state, scope, relationship, and risk constraints
→ score independent evidence families
→ require confidence and runner-up margin
→ revalidate the live control
→ select a typed interaction adapter
→ dispatch through Playwright
→ verify local state and the declared effect
```

The Browser Observation Runtime is a versioned self-contained function. It has no module closures or transpiler helpers, publishes a runtime hash, and blocks worker readiness if its integrity check fails. Observation failure, an empty inventory, incompatible controls, insufficient evidence, ambiguity, drift, dispatch failure, local-state failure, and effect failure remain distinct typed outcomes.

Local OCR produces visual anchors, never action targets. Geometry expands those anchors to nearby compatible controls. Canvas coordinates are admitted only as an explicit coordinate capability with canvas evidence and low-risk policy. Open Shadow DOM is observed through the browser runtime; closed Shadow DOM requires a reviewed origin-bound adapter.

Only sanitized fingerprints, evidence-family summaries, correlation groups, confidence, margins, drift, adapters, and safe actions are persisted. Full page graphs, internal selectors, protected values, clipboard contents, and temporary OCR images are not retained.

Unknown generated secrets remain governed by the calibrated acquisition contract and evidence-free protected capsule. A failed acquisition never repeats the one-time mutation. Recovery is bounded to approved alternate methods, secure assistance, revocation, abandonment, or expiration.

Accessibility quality is reported separately from functional compatibility. Poor markup may lower confidence or produce a quality finding, but it does not fail a functional interaction when independent browser-observable evidence establishes the compatible control safely.

Raw selectors are prohibited in Flow, API, MCP, calibration, report, and agent-authored contracts. Reviewed internal adapters are bounded by registered purpose, origin, configuration schema, privacy suppression, and release capability. Model-assisted reasoning remains disabled.
