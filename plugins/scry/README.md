# Scry

Connect your AI assistant to your existing Scry workspace, test an application
you are authorized to use, and review the resulting reports and evidence.

Use Scry's Connections page for the supported setup steps for your client.
ChatGPT accounts with plugin-upload support can use Plugins → Add → Upload plugin
archive. Desktop / Codex users can open the assisted setup from Connections.
Other clients can use their custom MCP connection workflow. Host availability and
account permissions still apply; a local install does not also install on the web.
The plugin does not include credentials. Sign in through the client-initiated Scry
consent page and approve one workspace. Installation alone does not verify access.

The package is a local distribution candidate, not an approved directory listing.
Its release metadata is package metadata, not a new Scry product baseline.
Keep required client approvals in place. The plugin does not install a browser
on the customer's computer; testing runs on Scry's service.
